# Поиск мостов в графе (DFS-алгоритм)

## Что такое мост?

**Мост** (или критическое ребро) — это ребро в графе, удаление которого увеличивает количество компонент связности. Иначе говоря, если убрать мост, часть графа станет недоступной.

---

## Зачем искать мосты?

- Анализ надёжности сетей.
- Поиск уязвимых связей в распределённых системах.
- Определение критических точек в социальных или транспортных сетях.

---

## Алгоритм поиска мостов (DFS)

### Этапы

1. Запускаем обход графа в глубину (DFS).
2. Для каждой вершины записываем:
    - **Время открытия** — когда вершина впервые посещена.
    - **Минимальное время открытия среди достижимых** — включая обратные рёбра.
3. Ребро (u, v) — мост, если после обхода v выполняется условие `low[v] > disc[u]`.

---

## Пример на Python

```python
def find_bridges(graph):
    n = len(graph)
    time = [0]  # Счетчик
    disc = [-1] * n
    low = [-1] * n
    bridges = []

    def dfs(u, parent):
        disc[u] = low[u] = time[0]
        time[0] += 1
        for v in graph[u]:
            if disc[v] == -1:
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if low[v] > disc[u]:
                    bridges.append((u, v))
            elif v != parent:
                low[u] = min(low[u], disc[v])

    for i in range(n):
        if disc[i] == -1:
            dfs(i, -1)
    return bridges

# Пример графа (список смежности)
graph = [
    [1, 2],    # 0
    [0, 2],    # 1
    [0, 1, 3], # 2
    [2]        # 3
]
print(find_bridges(graph))  # Вывод: [(2, 3)]
```

---

## Свойства

- **Временная сложность:** O(V + E)
- **Память:** O(V)
- Работает для неориентированных графов.
- Находит все мосты за один обход в глубину.

---

## Применение

- Анализ уязвимых точек компьютерных сетей.
- Планирование резервирования инфраструктуры.
- Анализ социальных сетей (поиск ключевых связей).
