# Алгоритм Беллмана-Форда

## Описание

Алгоритм Беллмана-Форда — это алгоритм поиска кратчайших путей от одной вершины, который работает с графами с отрицательными весами рёбер и умеет обнаруживать отрицательные циклы. В отличие от алгоритма Дейкстры, Беллман-Форд подходит для графов, где веса рёбер могут быть отрицательными, и необходима проверка наличия циклов отрицательного веса (например, в задачах валютных обменов или оптимизации стоимости).

---

## Как работает

1. Инициализируем расстояние до источника как 0, до остальных вершин — как бесконечность.
2. V-1 раз (где V — число вершин) "расслабляем" все рёбра, обновляя кратчайшие пути.
3. После V-1 прохода снова проверяем все рёбра:
   - Если удаётся улучшить путь, значит есть цикл отрицательного веса.

---

## Пример на Python

```python
def bellman_ford(graph, source):
    # graph: список рёбер (u, v, вес)
    distance = {v: float('inf') for v in graph['vertices']}
    distance[source] = 0

    for _ in range(len(graph['vertices']) - 1):
        for u, v, w in graph['edges']:
            if distance[u] + w < distance[v]:
                distance[v] = distance[u] + w

    # Проверка на отрицательные циклы
    for u, v, w in graph['edges']:
        if distance[u] + w < distance[v]:
            raise Exception("Граф содержит цикл отрицательного веса")

    return distance

# Пример графа
graph = {
    'vertices': ['A', 'B', 'C', 'D'],
    'edges': [
        ('A', 'B', 1),
        ('B', 'C', 3),
        ('A', 'C', 10),
        ('C', 'D', 2),
        ('D', 'B', -10)
    ]
}
print(bellman_ford(graph, 'A'))
```

---

## Объяснение кода

- Словарь `distance` хранит кратчайшие расстояния от источника до каждой вершины.
- Шаг "расслабления" обновляет известные кратчайшие пути.
- Финальная проверка обнаруживает циклы отрицательного веса.

---

## Временная и пространственная сложность

- **Время:** O(V * E)
- **Память:** O(V)

---

## Где применяется

Беллман-Форд полезен для:
- Графов с отрицательными рёбрами.
- Поиска арбитража на валютных рынках.
- Поиска кратчайших путей в протоколах маршрутизации (например, RIP).
- Задач оптимизации затрат.

---

## Где использовать — плохо

- Медленный для плотных графов; уступает по скорости Дейкстре на графах без отрицательных рёбер.
- Не рекомендуется для очень больших графов, где критична производительность.
