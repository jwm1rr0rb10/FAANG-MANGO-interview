Группы алгоритмов и применение (кратко)
- Обходы и поиски (BFS, DFS, A*): базовые строительные блоки для большинства graph-проблем — используются в маршрутизации, анализе связности, поиске путей, игровом AI.
- Кратчайшие пути (Dijkstra, Bellman-Ford, Floyd-Warshall, A*): маршрутизация, картография, логистика, оптимизация затрат.
- Связность/компоненты (Tarjan, Kosaraju, Articulation points, Bridges): анализ структуры, отказоустойчивость, компоненты связанности.
- MST / Min-Cut (Kruskal, Prim, Stoer-Wagner): сеть, кластеризация, минимизация затрат построения сети.
- Потоки и паросочетания (Dinic, Edmonds-Karp, Ford-Fulkerson, Hopcroft-Karp): распределение ресурсов, задачи соответствия, сеть с пропускной способностью.
- Специальные пути (Eulerian, Hamiltonian): задачи маршрутизации, оптимизации обходов; Гамильтоновы задачи — NP-трудные.
- DAG-алгоритмы (Topological Sort): планирование задач, компиляция зависимостей.
- Прочее: алгоритмы с узкой, но важной областью применения.

Полный список алгоритмов (алгоритм → описание, time, space, примечания)

1) A* Search
- Описание: эвристический поиск кратчайшего пути от стартовой вершины до цели; использует функцию f = g + h.
- Временная сложность: зависит от эвристики; в худшем случае может деградировать до Dijkstra (и дальше в экспоненциальный при плохой эвристике). Для типичной реализации с бинарной кучей: O((V + E) log V) ≈ O(E log V) (если E ≥ V). При использовании Фибоначчиевой кучи: O(E + V log V).
- Пространственная сложность: O(V) (open/closed множества, g/h/f и parent-массивы).
- Применение: навигация в играх, робототехника, картография.
- Примечание: качество эвристики (адмиссивность, согласованность) сильно влияет на производительность.

2) Articulation Points (DFS-based)
- Описание: находит точки сочленения (вершины, удаление которых увеличивает число компонент связности).
- Временная сложность: O(V + E).
- Пространственная сложность: O(V) (вспомогательные массивы, стек рекурсии).
- Применение: анализ отказоустойчивости сетей, критические узлы.

3) Bellman-Ford
- Описание: находит кратчайшие пути из источника при возможных отрицательных ребрах; обнаруживает отрицательные циклы.
- Временная сложность: O(V * E).
- Пространственная сложность: O(V) (массив dist и предков).
- Применение: финансовые расчёты, маршрутизация со штрафами; когда могут быть отрицательные веса.

4) Breadth-First Search (BFS)
- Описание: уровень-за-уровнем обход; находит кратчайшие пути в невзвешенных графах.
- Временная сложность: O(V + E).
- Пространственная сложность: O(V) (очередь + visited + parent).
- Применение: короткие пути в невзвешенных графах, поиск компонент, минимальные переходы.

5) Bridge Finding (DFS-based)
- Описание: находит мосты — ребра, удаление которых увеличивает число компонент.
- Временная сложность: O(V + E).
- Пространственная сложность: O(V).
- Применение: анализ устойчивости связей, сетевой дизайн.

6) Depth-First Search (DFS)
- Описание: рекурсивный/стековый обход в глубину; используется в топологической сортировке, обнаружении циклов и т.д.
- Временная сложность: O(V + E).
- Пространственная сложность: O(V) (рекурсивный стек + visited).
- Применение: базовый инструмент для многих graph-алгоритмов.

7) Dijkstra's Shortest Path
- Описание: кратчайшие пути из источника при неотрицательных весах.
- Временная сложность: с бинарной кучей O((V + E) log V) ≈ O(E log V) для разреженных графов; с Фибоначчиевой кучей O(E + V log V); с матрицей смежности O(V^2).
- Пространственная сложность: O(V) (dist, prev, структура очереди).
- Применение: маршрутизация, навигация, оптимизация затрат.

8) Dinic's Algorithm (Max Flow)
- Описание: быстрый алгоритм для максимального потока, использует построение уровневого графа и поиск блочных потоков.
- Временная сложность: в худшем случае O(V^2 * E). На практике и для многих классов графов — значительно быстрее; для сетей с единичными пропускными способностями O(min(V^(2/3), E^(1/2)) * E).
- Пространственная сложность: O(V + E).
- Применение: задачи потоков, распределение ресурсов, задачи паросочетаний (через потоки).

9) Edmonds-Karp (Max Flow, BFS augmenting)
- Описание: специальная реализация Ford–Fulkerson, где каждый раз выбирается кратчайший по рёбрам путь (BFS) — даёт гарантированные границы.
- Временная сложность: O(V * E^2).
- Пространственная сложность: O(V + E).
- Применение: целевые задачи максимального потока с умеренными размерами графа.

10) Eulerian Path / Circuit
- Описание: ищет путь/цикл, проходящий по каждому ребру ровно один раз (условия на степени вершин).
- Временная сложность: O(V + E) (например, алгоритм Хиернса/Флейри с эффективной реализацией).
- Пространственная сложность: O(V + E) (стек / список пути + копия графа для удаления рёбер).
- Применение: маршрутизация, задачи обхода ребер (почта, сборка маршрутов).

11) Floyd–Warshall (All-Pairs Shortest Path)
- Описание: динамическое программирование для кратчайших путей между всеми парами вершин.
- Временная сложность: O(V^3).
- Пространственная сложность: O(V^2) (матрица расстояний; можно хранить и next-массив для восстановления путей).
- Применение: небольшие плотные графы, предобработка расстояний, вычисление транзитивного замыкания.

12) Ford–Fulkerson (Max Flow)
- Описание: классический мето�� увеличения потока по путям в остаточной сети.
- Временная сложность: O(E * f) (f — величина максимального потока). При целочисленных вместимостях — гарантированно завершится; при вещественных — возможны проблемы.
- Пространственная сложность: O(V + E).
- Применение: базовый метод; на практике используют Edmonds-Karp или Dinic для гарантированных оценок.

13) Hamiltonian Path
- Описание: путь, проходящий через каждую вершину ровно один раз. Задача NP-полна.
- Временная сложность: факториальная для наивных переборов O(n!) в худшем случае; динамическая програм. Held–Karp — O(n^2 * 2^n) по времени и O(n * 2^n) по памяти.
- Пространственная сложность: наивный — O(n) (рекурсия); DP — O(n * 2^n).
- Применение: коммивояжёрские задачи, перестановки; редко применимо на больших n.

14) Hopcroft–Karp (Bipartite Matching)
- Описание: находит максимальное паросочетание в двудольном графе быстрее, чем простые наращивающие пути.
- Временная сложность: O(√V * E).
- Пространственная сложность: O(V + E).
- Применение: задачи назначения, распределения задач/ресурсов.

15) Kosaraju's SCC
- Описание: находит сильно связные компоненты двумя обходами DFS (обратный граф + порядок обхода).
- Временная сложность: O(V + E).
- Пространственная сложность: O(V + E).
- Применение: анализ направленных графов, оптимизация зависимостей.

16) Kruskal's MST
- Описание: строит MST сортировкой рёбер и использованием DSU (union-find).
- Временная сложность: O(E log E) = O(E log V) (сортировка рёбер), при равномерном E.
- Пространственная сложность: O(V + E) (хранение рёбер и DSU).
- Применение: проектирование сетей, минимизация затрат на соединение узлов.

17) Min-Cut (Stoer–Wagner)
- Описание: алгоритм глобального минимального разреза для неориентированных графов.
- Временная сложность: O(V^3) (типичное оценивание).
- Пространственная сложность: O(V^2) или O(V + E) в зависимости от представления; часто используется матрица сумм для ускорения.
- Применение: кластеризация, анализ слабых мест сети.

18) Prim's MST
- Описание: строит MST, расширяя дерево от начальной вершины (подобно Dijkstra).
- Временная сложность: с бинарной кучей O((V + E) log V) ≈ O(E log V) для разреженных; с матрицей смежности O(V^2).
- Пространственная сложность: O(V + E).
- Применение: как Kruskal; выгоден при матрице смежности или плотных графах (версия O(V^2)).

19) Tarjan's SCC
- Описание: однопроходный алгоритм для поиска сильно связных компонент с помощью low-link значений.
- Временная сложность: O(V + E).
- Пространственная сложность: O(V) (стек, индексы, low-link и т.д.).
- Применение: как Kosaraju, но часто предпочтительнее из-за одной DFS-проходки.

20) Topological Sort
- Описание: линейный порядок вершин DAG, удовлетворяющий ориентированным зависимостям (Kahn или DFS-версия).
- Временная сложность: O(V + E).
- Пространственная сложность: O(V + E) (входной граф + очередь / стек).
- Применение: планирование задач, разрешение зависимостей, компиляция.

Замечания по практическому использованию и точности сложностей
- При указании временных сложностей важно указывать структуру данных: Dijkstra и A* зависят от реализации приоритетной очереди (бинарная куча vs Фибоначчиева куча vs индексированная куча). В реальном коде чаще используют бинарную кучу (std::priority_queue / heap), поэтому формула O((V + E) log V) или O(E log V) чаще практична.
- Для алгоритмов максимального потока практическая производительность часто важнее худшего случая; Dinic обычно быстрее Edmonds-Karp и Ford-Fulkerson в больших задачах.
- Для NP-полных задач (Hamiltonian) необходимо информировать об экспоненциальной сложности и приводить альтернативы (эвристики, приближённые решения, DP для малых n).
- Пространственная сложность обычно учитывает дополнительные структуры (dist, parent, visited, стек-для-DFS). Хранение самого графа (adj-list или adj-matrix) не включено в «дополнительную» оценку; если граф хранится матрицей смежности, нужно учитывать O(V^2) уже за хранение входа.
