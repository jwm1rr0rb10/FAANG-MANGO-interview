#### Типы данных и синтаксис
**Пакеты и области видимости**
- Что такое пакеты в Go?
```text
Пакет (package) — это основной способ организации кода. Каждый файл в Go начинается с package name. Это позволяет группировать функции, типы и переменные. Пакеты обеспечивают модульность и повторное использование кода.
```
- Как работают области видимости в Golang?
```text
В Go область видимости определяется очень просто — **регистром первой буквы:**

 - **Экспортируемые (Public):** Если имя начинается с заглавной буквы (например, `fmt.Println`), оно доступно из других пакетов.

 - **Неэкспортируемые (Private):** Если с маленькой (например, `var secret string`), оно доступно только внутри текущего пакета.

 - **Локальные:** Переменные внутри функций доступны только в пределах блока `{}`.
```
- Что такое глобальная переменная и как ее объявить?
```text
Глобальная переменная (на уровне пакета) объявляется вне функций. Она доступна всем функциям в этом пакете.
```go
Go
package main

var GlobalVar = "Я видна везде" // Экспортируемая
var packageVar = "Я видна только в этом пакете" // Приватная
```
```

## Ключевые концепции Go

#### ООП в Go
Go не является чистым ООП-языком, но поддерживает ключевые принципы:
- **Инкапсуляция** - через пакеты (exported/unexported идентификаторы)
- **Наследование** - через композицию и встраивание структур
- **Полиморфизм** - через интерфейсы (утиная типизация)
- **Абстракция** - через интерфейсы и неэкспортируемые типы

#### Конкурентность vs Параллельность
- **Конкурентность** - выполнение нескольких задач, переключаясь между ними
- **Параллельность** - выполнение нескольких задач одновременно
- **Горутины** - легковесные потоки, управляемые рантаймом Go
- **Каналы** - способ коммуникации между горутинами (share memory by communicating)

#### Особенности Go
- Простая и читаемая синтаксическая структура
- Статическая типизация с выводом типов
- Сборка мусора
- Встроенная поддержка конкурентности
- Быстрая компиляция
- Статическая линковка (один бинарный файл)
