## Google Docs

Google Docs is a free cloud-based word processor developed by Google. It allows individuals and teams to create, edit, and collaborate on documents in real time from any internet-connected device. Integrated into Google Workspace, it is the cornerstone of online productivity and collaboration for millions of users worldwide. - [Google-Docs](https://www.britannica.com/topic/Google-Docs?utm_source=chatgpt.com)

### Key facts

- Launch year: 2006 (based on the acquired Writely service)
- Platform: Web, Android, iOS, ChromeOS
- Core package: Google Workspace
- AI assistant: Gemini in Docs (formerly Duet AI)
- Pricing: Free for individuals; premium version available through Workspace plans

---

### Origins and development

Google Docs evolved from Writely, an early browser-based text editor created by Upstartle in 2005. Google acquired it in 2006, merging it with the newly launched Google Apps suite (later renamed Google Workspace). Over time, Docs evolved from a simple online editor into a sophisticated cloud-based platform that competes with desktop text editors like Microsoft Word.[techtarget](https://www.techtarget.com/whatis/definition/Google-Docs?utm_source=chatgpt.com)

---

### Collaboration and functionality

- Docs allows multiple users to simultaneously edit the same file with real-time cursor tracking and color-coded changes. Built-in version history records every change, allowing users to review or restore previous edits. Collaboration tools include comments, suggestions, task assignments, and in-document chat. Offline mode allows you to continue editing without an internet connection, automatically syncing when you reconnect.[techtarget](https://www.techtarget.com/whatis/definition/Google-Docs?utm_source=chatgpt.com)

---

### Features and Integrations

- Google Docs supports common file types, including .docx, .pdf, and .txt, for seamless import and export. Templates, pageless documents, smart chips, and voice input enhance productivity. Integration with other Google apps—Drive, Gmail, Sheets, and Meet—allows users to embed diagrams, reply to comments via email, or start video calls directly within documents.[workspace](https://workspace.google.com/intl/gl/products/docs/?utm_source=chatgpt.com)

---

### AI-powered writing tools and smart tools

- Modern versions of Docs include artificial intelligence features from Gemini, Google's generative AI suite. Users can use Gemini to create drafts, refine or summarize text, generate structured documents, and get contextual "Help me write" suggestions. Additional assistive tools, such as Smart Compose, autocorrection, and built-in summaries, enhance writing fluency and efficiency.[workspace](https://workspace.google.com/intl/en_ie/products/docs/?utm_source=chatgpt.com)

---

### Security and Access

- Documents are encrypted in transit and at rest, and managed through user-defined sharing permissions. Workspace administrators gain access to enterprise-grade features such as client-side encryption, access logs, and compliance certificates. A Google account is all that's required for the free version, while business and education plans offer enhanced features and support.[google.es](https://www.google.es/intl/es-419///docs/about/?utm_source=chatgpt.com)

## Notion

Notion is collaboration software that combines note-taking, project management, database, and wiki features into a single, easily customizable platform. Developed by Notion Labs Inc., it allows individuals and teams to centralize documents, manage workflows, and seamlessly share knowledge across devices.

### Key Facts

| Attribute           | Detail                                                    |
|:--------------------|:----------------------------------------------------------|
| Developer           | Notion Labs Inc. (founded 2016, San Francisco)            |
| Platforms           | Web, macOS, Windows, iOS, Android                         |
| Latest rating       | 4.7 / 5 (Capterra, 2025)                                  |
| Primary users       | Individuals, small businesses and teams                   |
| Free level          | Yes, with paid Plus, Business, and Enterprise plans.      |

---

## Features and functionality

Notion combines databases, Kanban boards, calendars, and Markdown-based pages into a single workspace. Users can link these components to create systems for note-taking, knowledge management, or tracking complex projects. Templates and drag-and-drop editing simplify customization, and its AI assistant—powered by GPT-4 and Claude—supports summarization, content generation, and intelligent search. Integration with Slack, Google Drive, Trello, and other apps ensures seamless cross-platform collaboration.

---

### Collaboration and team spaces

Teams can create shared pages, leave comments in real time, assign tasks, and maintain corporate wikis. Team spaces and granular permissions support departments or project groups. Notion Calendar and the upcoming Notion Mail expand its ecosystem, providing planning and communication tools integrated into a single interface.

---

### Prices and tariff plans

As of 2025, Notion offers:

- Free plan: Basic collaboration features and file uploads up to 5 MB
- Plus: $12 per user per month
- Business: $18 per user per month, with advanced administration and privacy settings
- Enterprise: Custom pricing with single sign-on (SSO), audit logs, and dedicated support
  Users can add Notion AI for $10 per seat per month.
---

### Strengths and Weaknesses

Highly praised for its flexibility, design, and community‑built templates, Notion serves as an “all‑in‑one workspace” for personal and professional productivity. Drawbacks include a steep learning curve, limited offline functionality, and occasional lag with large databases. Nevertheless, it remains one of the world’s leading productivity platforms, widely used by startups, creatives, and knowledge‑focused organisations.

## Figma

Figma is a cloud‑based collaborative design and prototyping tool used for creating user interfaces, mobile apps, and digital products. It enables multiple people to work on the same file simultaneously, streamlining workflows among designers, developers, and stakeholders across platforms.

### Key Facts

- Founded: 2016
- Founders: Dylan Field and Evan Wallace
- Headquarters: San Francisco, California, USA
- Acquired by: Adobe Inc. (announced 2022; deal terminated 2023)
- Primary uses: UI design, prototyping, design systems, collaboration

---

### Origins and Development

Figma emerged from the idea of bringing design tools into the browser, simplifying sharing and feedback. Field and Wallace founded the company in 2012, focusing on real‑time collaboration using web technologies such as WebGL. The public release came in 2016, and the platform quickly gained popularity among design teams.

---

### Features and Workflow

Figma offers vector drawing, layout grids, and component systems to maintain design consistency. Its hallmark feature is multiplayer editing, where team members see each other’s cursors and changes in real time. Built‑in prototyping tools, developer handoff capabilities, and version history support an end‑to‑end workflow within a single platform.

---

### Ecosystem and Integrations

The platform is extended through plugins, templates, and community resources. FigJam, launched in 2021, adds an online whiteboard for brainstorming and workshops. Integrations with Slack, Notion, and developer tools embed Figma into broader product pipelines.

### Impact and Competition

Figma revolutionised UI design by moving from desktop‑bound software like Adobe XD and Sketch to a browser‑based, collaborative model. Its approach influenced the evolution of design systems and team workflows in the tech industry.

## Dropbox Paper

Dropbox Paper is a collaborative document editor developed by Dropbox. It lets teams create, share, and work on documents in real time, using text, media, and other files within a minimalist web‑based workspace. Initially launched in open beta in 2016, it has evolved into an integrated part of the Dropbox ecosystem.

### Key Facts

- Developer: Dropbox, Inc.
- First release: August 2016 (open beta)
- Latest update: 2025 – integrated into the Dropbox web workspace [turn0search0]
- Platform: Web; mobile apps discontinued in October 2025 [turn0search1]
- Pricing: Free with a Dropbox account

---

### Overview and Development

Paper started as Dropbox’s answer to tools like Google Docs, emphasising simplicity and rich media collaboration. Users can embed images, videos, audio, and code snippets directly into documents, making it popular among creative and project‑oriented teams. In 2020 and 2025, Dropbox released major updates that fully migrated Paper documents into the Dropbox file system for unified storage and management [turn0search0][turn0search6].

---

### Features and Functionality

Dropbox Paper supports real‑time collaborative editing, @‑mentions, to‑do lists, and calendar integration. Each document can contain formatted text, embedded media, and linked Dropbox files. Version history, comment threads, and task assignments are included, and documents occupy minimal storage – typically under 100 bytes. Teams can control access using standard Dropbox sharing permissions, with admin settings available for enterprise accounts.

---

### Integration and Access

Paper primarily operates within the main Dropbox web interface at dropbox.com/paper and syncs with existing Dropbox folders. Standalone mobile and desktop apps were discontinued in October 2025, but the full web version remains accessible on all devices via browsers [turn0search1][turn0search3]. Dropbox’s unified API now manages both Paper and regular files, simplifying search, sharing, and backup on a single content platform [turn0search0].

---

### Reviews and Usage

Critics and reviewers note Paper’s clean, flexible design as both a strength and a drawback – it is ideal for brainstorming and collaboration but lacks advanced formatting compared to traditional word processors [turn0search8]. Nevertheless, it remains a lightweight and accessible solution for teams seeking integrated, media‑rich collaboration inside Dropbox.

### 7. Real-Time Sync Mechanisms

There are two main algorithms.

#### 7.1 Operational Transform (OT)

Используется в:
- Google Docs

**Idea:**

Transform operations so that the order of changes is preserved.


**Example.**

User A:
```text
User A:
```

User B:
```
delete position 3
```

The server transforms the operations:

```text
transform(opA, opB)
```

to maintain consistency.

OT Pros
- mature technology
- efficient for text editors

---

OT Cons
- complex implementation
- difficult to scale

---

#### 7.2 CRDT (Conflict-Free Replicated Data Types)

Used in:
- Figma
- Automerge

**CRDT allows:**

replicas to converge to the same state without central coordination.

**Each element gets a unique ID.**

Example structure:
```text
Character
---------
id
value
parent
timestamp
```

**Pros**
- works offline
- easier to scale

**Cons**
- larger data size
- complex optimisation
